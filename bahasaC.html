Bahasa C

Bahasa pemrograman C adalah bahasa pemrograman tujuan umum yang diciptakan oleh Dennis Ritchie pada tahun 1972 untuk Sistem Operasi Unix di Bell Telephone Laboratories. Awalnya dirancang untuk pemrograman sistem dan jaringan komputer, C juga banyak digunakan dalam pengembangan perangkat lunak aplikasi di berbagai platform sistem operasi dan arsitektur komputer. Pengaruhnya sangat besar terhadap bahasa pemrograman lain, terutama C++, yang merupakan ekstensi dari C. Selain itu, berbagai compiler populer tersedia untuk C, dan sejak tahun 2000, bahasa ini secara konsisten menduduki peringkat atas dalam indeks popularitas bahasa pemrograman seperti TIOBE.

Contoh Kode C

                    
                        #include  // Library standar untuk input dan output

                            int main() {
                                // Mencetak "Hello, World!" ke layar
                                printf("Hello, World!\n");
                            
                                // Mendeklarasikan dua variabel integer dan satu variabel untuk hasil
                                int a, b, sum;
                            
                                // Menginisialisasi nilai variabel
                                a = 5;
                                b = 7;
                            
                                // Menjumlahkan a dan b
                                sum = a + b;
                            
                                // Mencetak hasil penjumlahan
                                printf("Hasil penjumlahan %d + %d adalah %d\n", a, b, sum);
                            
                                return 0; // Mengembalikan nilai 0 menandakan program selesai dengan sukses
                            }
