Python

Python adalah bahasa pemrograman tingkat tinggi yang dibuat oleh Guido van Rossum dan pertama kali dirilis pada tahun 1991. Dengan filosofi desain yang menekankan keterbacaan kode melalui penggunaan spasi putih signifikan, Python mendukung berbagai paradigma pemrograman seperti prosedural, berorientasi objek, dan fungsional. Diketik secara dinamis dan dilengkapi pengumpulan sampah, Python dikenal sebagai bahasa "termasuk baterai" karena perpustakaan standarnya yang kaya. Dirancang sebagai penerus bahasa ABC, Python mengalami pembaruan besar dengan rilis Python 2.0 pada tahun 2000 dan Python 3.0 pada 2008, yang memperkenalkan fitur baru namun tidak sepenuhnya kompatibel dengan versi sebelumnya. Penerjemah Python tersedia untuk banyak sistem operasi, dengan CPython sebagai implementasi referensi sumber terbuka yang dikelola oleh Python Software Foundation. Python konsisten menjadi salah satu bahasa pemrograman paling populer di dunia.

                    # Mencetak "Hello, World!" ke layar
                    print("Hello, World!")

                    # Mendeklarasikan dua bilangan

                    # Menjumlahkan kedua bilangan

                    print(f"Hasil penjumlahan {a} + {b} adalah {sum}")
