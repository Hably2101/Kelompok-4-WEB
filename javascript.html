Javascript

JavaScript (JS) adalah bahasa pemrograman tingkat tinggi dan dinamis yang populer di internet dan dapat dijalankan di sebagian besar penjelajah web seperti Google Chrome, Mozilla Firefox, dan Opera. Sebagai salah satu teknologi inti web bersama HTML dan CSS, JavaScript memungkinkan pembuatan halaman web interaktif serta aplikasi web yang esensial. Awalnya berfungsi sebagai client-side dalam browser, JavaScript kini digunakan pada server-side, perangkat lunak non-web, dan runtime environment untuk aplikasi desktop dan mobile. JavaScript adalah merek dagang yang dikelola oleh Oracle Corporation.
